## Work Model — Collaborative Frontend/Backend Split

Each story is split into a **frontend half** and a **backend half**, worked simultaneously by two students. The **OpenAPI spec** (defined in Sprint 1) is the shared contract: the frontend developer mocks API responses while the backend developer implements real endpoints. Both halves merge when the backend is ready.

> 🔵 FE = frontend layer · 🟠 BE = backend layer  
> 🔴 Large story · 🟡 Medium · 🟢 Small · ⚡ Critical path blocker

### Principles

1. **OpenAPI as contract** — FE and BE develop in parallel using mocks; merge when backend is ready.
2. **FE developer owns:** Angular component, template, service, route, `.spec.ts` tests.
3. **BE developer owns:** Spring controller, service, repository, JPA entity, Flyway migration, JUnit tests.
4. **The story file** (generated by `bmad-create-story`) is shared by both FE and BE developers on the same story.
5. **Sprint-status.yaml** — story moves to `done` only when both layers pass code review.
